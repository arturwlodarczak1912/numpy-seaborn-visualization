# NumPy Fundamentals & Data Visualization with Seaborn

## 🎯 Project Goal
Practical application of vectorized operations using **NumPy** and building statistical data visualizations with **Seaborn** on a real-world car sales dataset.

## 📊 Dataset
[Car Sales](https://www.kaggle.com/datasets/gagandeep16/car-sales) (Kaggle)

## 🛠️ Key Tasks & Accomplishments
- **NumPy Fundamentals:** Working with arrays, vectorization, and fast bulk operations (significantly more efficient than standard Python loops).
- **Data Aggregation:** Calculating summary statistics (e.g., average price per manufacturer) and generating new DataFrames.
- **Statistical Visualization:** Analyzing feature correlations and data distributions using Seaborn (heatmaps, scatter plots).

## 🧰 Tech Stack
`Python` `NumPy` `Pandas` `Seaborn` `Matplotlib`
